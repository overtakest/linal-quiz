# 📐 АиГ — подготовка к экзамену по линейной алгебре (Telegram Mini App)

Линейная алгебра и геометрия, 2 семестр: все **56 экзаменационных билетов** (`linear_alg-4.pdf`).
Материал составлен по «Лекциям АиГ, 2 семестр».

Путь подготовки: **теория → отработка → экзамен с оценкой**.

| Вкладка | Что делает |
|---|---|
| **📖 Теория** | 287 карточек по всем пунктам билетов: определения, теоремы с доказательствами (как в лекциях), примеры, алгоритмы, а у каждой — «Что обязательно написать». Отметка «изучено», прогресс по билетам, поиск, режим «🙈 Проверить себя» (тексты скрыты, открываются по нажатию). |
| **✍️ Отработка** | *Письменно*: по каждой карточке задание («Сформулируйте и докажите…»), ответ текстом или фото листка, затем сверка с эталоном и чек-лист либо проверка ИИ. *Тесты*: 562 вопроса пяти типов, фильтр по билету, подсказки после ответа. |
| **🎓 Экзамен** | Выпадает 2 билета → теория пишется на листке, фото отправляется прямо из приложения → ИИ проверяет по эталону (или самопроверка) → тесты по этим билетам на время → **оценка 2–5** с разбором. Там же пробный тест на 40 вопросов. |
| **🔥 Входной контроль** | 5 вариантов, которые реально были на входном контроле, и 13 вариантов для подготовки из файла группы. По 5 вопросов, ответ раскрывается по кнопке, рядом — переход к билету и его шпора. Плюс список «остальные возможные темы» и кнопка случайного варианта. |
| **🖨 Шпоры** | `print.html` — все 56 билетов на нескольких листах A4 (2–4 колонки на выбор), темы с реального контроля помечены 🔥, можно печатать только их. Та же шпора видна на странице билета. |
| **👤 Профиль** | Прогресс теории и тестов, средний балл письменных ответов, история экзаменов и оценки, дизайн и тема. |

### Оценка за экзамен
Итог = `theoryWeight` × теория + (1 − `theoryWeight`) × тесты. По умолчанию 60/40, «5» от 85%,
«4» от 70%, «3» от 50%; если теория любого билета ниже 30% — «2». Всё настраивается в
`assets/config.js` → `exam`.

### Проверка теории ИИ
Мини-приложение — статический сайт, а проверка идёт через Cloudflare Worker из папки `bot/`.
Он же работает как Telegram-бот. Воркер хранит ключ Anthropic, проверяет подпись Telegram и вызывает
Claude. Инструкция: [`bot/DEPLOY-BOT.md`](bot/DEPLOY-BOT.md). Пока `apiUrl` в `assets/config.js`
пустой, всё работает, но теория оценивается самопроверкой по чек-листу.

Материалы рядом с папкой приложения:
- `../Теория_линал_2_семестр.md` — вся теория одним документом (то же, что в карточках);
- `../Ответы_линал_2_семестр.md` — краткая шпаргалка по билетам.

## 🚀 Запуск

1. **Приложение → GitHub Pages.** Создай публичный репозиторий `linal-quiz`, загрузи содержимое этой
   папки (`index.html`, `assets/`, `data/`, `.nojekyll`; папку `bot/` можно тоже, без `node_modules`).
   Затем *Settings → Pages* → `main` / `(root)`.
   Адрес будет `https://ТВОЙ_ЛОГИН.github.io/linal-quiz/`.
2. **Бот и проверка → Cloudflare Worker.** Инструкция в [`bot/DEPLOY-BOT.md`](bot/DEPLOY-BOT.md):
   `npm install` → секреты `BOT_TOKEN`, `ANTHROPIC_API_KEY` → `npx wrangler deploy` → открыть `/setWebhook`.
3. Впиши адрес воркера в `assets/config.js` → `apiUrl` и перезалей сайт.

Прогресс хранится в Telegram CloudStorage (синхронизация между устройствами) с копией в
localStorage под префиксом `laq_`, отдельно от других приложений на том же `github.io`.
Фото листков никуда не сохраняются: они уходят только в запрос проверки.

## 📁 Структура
```
linal-quiz/
├── index.html
├── assets/
│   ├── app.js        # ядро: тесты, фильтры, пробный тест, профиль, админка
│   ├── study.js      # теория, письменная отработка, экзамен по билетам, оценка
│   ├── study.css     # стили новых разделов (поверх любого скина)
│   ├── config.js     # adminIds, apiUrl, параметры экзамена и шкала оценок
│   └── skins/*.css
├── print.html        # шпоры по всем билетам для печати / PDF
├── data/
│   ├── theory.json     # 56 билетов → 287 карточек (text, proof, keyPoints, prompt, note)
│   ├── cheat.json      # короткая шпора по каждому билету (5–9 строк)
│   ├── entry.json      # входной контроль: варианты, вопросы, короткие ответы, привязка к билетам
│   ├── questions.json  # 562 тестовых вопроса; topic = «N. Название билета»
│   └── tips.json       # пояснение к каждому вопросу
└── bot/                # Cloudflare Worker: Telegram-бот + /api/grade (Claude API)
    ├── src/worker.js
    ├── wrangler.toml
    └── DEPLOY-BOT.md
```

### Формат карточки теории
```json
{"id":"07-01","kind":"Определение","title":"Линейное подпространство",
 "text":"…","proof":"…","keyPoints":["…","…"],"prompt":"Запишите определение…","note":""}
```
`keyPoints` — критерии проверки: по ним работает и самопроверка, и ИИ.
